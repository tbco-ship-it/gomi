年末年始のごみ出し

{% if yearend_guide.same_period %}{% set yw = yearend_guide.window %}

対応している{{ cities|length }}市区はいずれも{{ yw.start_month }}月{{ yw.start_day }}日から{{ yw.end_month }}月{{ yw.end_day }}日までは収集がお休みです。{{ yw.last_collection }}までに出しきり、年明けは休止明けの最初の収集日から通常どおりです。祝日はふだん通り収集されます(年末年始だけが例外)。

{% else %}

対応している{{ cities|length }}市区の年末年始の休止期間は市区ごとに異なります。休止期間と休止前の最終収集日は、下の市区別一覧で確認してください。祝日の収集は市区の通常ルールに従います。

{% endif %}

このサイトの「今日と明日」表示と週カレンダーは、この期間を自動で除いて次の収集日を出します。市が別途「年末年始特別収集」を告知した場合はそちらが優先です。

年末に多いごみの出し方

  • 大掃除の可燃ごみ: 12月最後の収集日は量が多く、時間が遅れがちです。前日夜ではなく当日朝に、いつもの時間までに。
  • 粗大ごみ: 12月は申込が最も混み、12月中旬には年内枠が埋まる市が多いです。年内に出すなら11月中に申込を。
  • びん・缶・ペットボトル: 年末年始で家庭内に溜まりやすいので、1月最初の資源日を町丁目ページで確認しておくと楽です。
  • 年賀状・ダンボール: 古紙(資源)。ひもでしばって、資源の日に。

年始の最初の収集日

年始は各市区の休止明け、最初に該当する曜日から通常収集です。このサイトの町丁目ページは市区ごとの休止期間を飛ばして次の収集日を計算します。
